ShopSure – QA Capstone Project



Quales Consulting | Cohort 22



1\. Project Overview



ShopSure is an end-to-end software quality assurance capstone project focused on testing an e-commerce application. The project covers API testing, JavaScript fundamentals, UI automation, and test reporting.



Application under test: https://www.automationexercise.com



2\. Testing Scope



The project covers:



API testing using Postman.



API test execution using Newman.



JavaScript fundamentals and test scripting.



UI testing using Playwright.



Page Object Model (POM) implementation.



Cross-browser testing with Chromium and Firefox.



HTML test reporting.

4\. API Testing – Postman and Newman



A Postman collection named ShopSure API was created to validate the application's API endpoints.



The collection contains 14 requests covering the available API operations.



Validation included:



HTTP status code checks.



Response code and response message validation.



Response body assertions.



JSON schema validation.



Product and search response validation.



User account operations.



The collection was executed using Newman.



Execution result: The generated Newman HTML report recorded zero failed tests.



Report location: reports/newman/shopsure-api-report.html



5\. UI Automation – Playwright



Playwright was used to automate e-commerce user journeys on the application.



The test suite contains nine user journeys configured to run on:



Chromium



Firefox



The project uses the Page Object Model to organise page interactions and reusable methods.



Additional implementation includes:



Web-first assertions.



Configured test and assertion timeouts.



HTML reporting.



Trace collection on first retry.



Headless browser execution.



Playwright configuration: playwright.config.js



Test location: tests/



6\. JavaScript Practice



JavaScript exercises were completed as part of the QA programme, covering functions, arrays, loops, and template literals.



The exercises supported the development of scripting fundamentals used in test automation.

8\. Findings and Observations



The API collection's latest Newman execution generated an HTML report showing zero failed tests.



During UI automation, some Playwright tests experienced intermittent failures against the live application. The live environment's response and stability can affect automated execution. These results should be reviewed in the generated Playwright report.



The project demonstrates API validation, UI automation, reusable test structure, cross-browser execution, and test reporting.
